安装与启动

  1. 下载 Windows 安装包（.exe），双击运行。
  2. 选择安装目录，完成安装后桌面会出现快捷方式。
  3. 首次启动需选择工作目录（本地 Markdown 文件夹），之后自动记忆。
  4. 支持多工作路径，在设置中可添加、切换或移除。

文档编写规范

  • 支持标准 Markdown 语法，包括标题、列表、表格、代码块、引用等。
  • Frontmatter 支持(title、date、tags 等元信息字段)。
  • 文档间链接使用 [文本](相对路径.md) 格式，图谱会自动识别关联。
  • 支持数学公式（LaTeX 语法）、Mermaid 图表、Excalidraw 绘图。
  • 高亮标注块：:::tip / :::warning / :::note 等。

图谱标记与维护

  • 文档之间的链接关系自动生成知识神经图谱。
  • 最新文档自动居中，有链接的文档互相引力更强。
  • 拖拽节点松开后按引力规则缓慢复原。
  • 图谱运动参数可在设置中调节，不查看时不占用 GPU。

主题与外观

  • 内置深色、明亮、护眼、柔光四种核心主题。
  • 柔光主题：暖琥珀金强调色，低饱和度，适合长时间写作。
  • 图片主题：上传背景图并自动取色，支持文字明暗切换。
  • 字体、字号、窗口缩放均可自定义，重启后自动恢复。

可选辅助功能

  • 默认关闭，在设置中按需开启，不干扰核心编辑与阅读体验。
  • 支持本地或云端模型接入，模型配置在设置中填写。
  • 提供选中翻译、润色续写、代码补全与生成注释等辅助能力。
  • 问答侧栏助手回复可一键润色、续写或插入到当前文档。
  • 所有辅助功能均可独立开关，按需使用。

快捷键参考

全局快捷键（任意位置可用）：

  • Alt+A 区域截图（标注 + OCR） · Alt+M 区域录屏（WebM）
  • F2 重命名文档 · Alt+E 切换编辑/阅读模式 · Alt+O 沉浸模式
  • Alt+Q 大纲目录 · Alt+W 预览栏 · Ctrl+Q 工作区目录
  • Ctrl+U AI 智能检索 · Ctrl+Shift+I 导入文档 · 双击 Shift 全局搜索
  • Ctrl+= 放大字体 · Ctrl+- 缩小字体 · Ctrl+0 重置缩放 · Esc 退出沉浸

编辑器快捷键：

  • Ctrl+B 加粗 · Ctrl+I 斜体 · Ctrl+K 链接
  • Ctrl+1/2/3 一/二/三级标题 · Ctrl+S 保存
  • Ctrl+F 关键字检索 · Ctrl+Shift+F 沉浸编辑 · Esc 退出沉浸/多光标
  • Tab 缩进 · Ctrl+Shift+7/8 有序/无序列表
  • Ctrl+Z 撤销 · Ctrl+Y 重做 · Ctrl+D 复制行 · Ctrl+M 删除行
  • Ctrl+; 插入日期 · Ctrl+' 插入时间
  • F3 / Ctrl+G 查找下一个 · Ctrl+Alt+↑/↓ 多处光标 · Ctrl+Shift+L 选中全部匹配

AI 辅助快捷键

  • Ctrl+Shift+A 代码补全 · Ctrl+Shift+/ 生成注释
  • Ctrl+Shift+P 润色 · Ctrl+Shift+X 续写
  • Ctrl+U 顶部智能检索 · Ctrl+I 行内对话
  • 辅助快捷键需在设置中开启对应功能后生效
