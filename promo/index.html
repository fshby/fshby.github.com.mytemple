最近更新

  • v2.2.5 云同步可靠性修复 — 个别含脚本的 .html 文档点「一键推送」永远传不上云端，原因是正文命中平台内容安全策略被服务端拒写（连空 <script> 标签都算），而该拒绝响应不携带跨源响应头，浏览器一律报成误导性的「缺少 Access-Control-Allow-Origin 头」，看着像跨源问题。现在：推送前把 HTML 的脚本剥离成「云端安全形态」再上传（本机文件一个字节不动），失败改为逐篇定位并把原因写进同步面板，只有被拒的 HTML 走降级重试、同批其他文档不受牵连，失败文档不再被标记为已同步（下次自动重试），从云端拉回时也不会用剥离版覆盖本机完整正文；云端与分享页阅读时会明确提示「云端版已移除脚本」。自动化测试 245→251 全绿，真浏览器端到端验证 13/13。
  • v2.2.4 HTML 文档阅读体验修复 — 手机上打开 .html 比浏览器里窄一截（响应式网页只剩 91% 宽、固定宽度网页只剩 32%）、长网页被 20000px 高度上限截断成双层滚动、同一文档反复打开完全不收敛（srcdoc 没有 URL，HTTP 缓存用不上）。现在：高度上限提到 200000px、云端与分享页补上「放大」全屏入口（全屏铺满、100vh 恢复真实视口）、补上正文与成品预览的会话内缓存（重开 0 次网络请求 84ms，首次 190ms）；顺手修桌面端放大后关闭不恢复页面滚动。预览仍在沙箱内运行，安全边界不变。
  • v2.2.3 图片同步修复 — 桌面端「一键推送」的截图 / 视频此前永远传不上去（真浏览器实测复现：官方 SDK 的存储请求会带两个平台 CORS 白名单里没有的头，预检直接被拦、请求根本不发出；登录与文档的头都在白名单内，所以「文档能同步、图片永远缺失」）。资产上传改为只带白名单头的直连请求，body 契约不变。同时修掉两个放大器：上传失败也照写「已核对」戳（一次失败就永久不再重试）、异常被静默吞掉（现在失败原因会写进同步结果）。旧版本留下的核对戳一律作废，升级后对工作区点一次「一键推送」即可补齐历史缺失的图片。
  • v2.2.2 独立的 .html 文件也能同步到云端 — 桌面端一直把 .html 当一等公民（网页预览、去标签检索），只有同步白名单没放行，本机能看、云端永远没有；云端工作台与分享页按扩展名分派渲染（沙箱网页 + 随分享带走的图片），单个文档设 1.2MB 上限，超限会明确报数。.json / .csv 仍不同步（工作区里的配置文件常含密钥，自动上云等于泄漏）。
  • v2.2.1 手机端截图不再「未同步」 — 桌面端「一键推送」补齐图片 / 视频（此前只搬正文，推上去的库文档在、图片全缺，手机与网页只能显示「未同步」占位）；正文没变也会按引用补齐历史缺失图片，云端已有则只探针不重传。分享出去的网页补上内嵌卡片样式与高度自适应，不再被压在 300×150 小窗里。安卓启动第一帧改为品牌方牌与品牌底色（此前是系统占位图标），启动屏受控收起。Android 客户端 1.1.2。
  • v2.2.0 重命名后缀修复 — 重命名时显式写的扩展名（如 hello.html）不再被强行改成 hello.html.md；不写扩展名仍自动补 .md；「仅显示 md」工作区下的边界行为改为明确提示。同批随 2.1.42 的内嵌网页体验修复。
