最近更新

  • v2.3.12 低显存模式真正生效 — ①开关接上 WebView2 内存使用目标（MemoryUsageTargetLevel）：此前只删毛玻璃与大阴影，对占大头的解码图片缓存、光栅 tile 缓存、GPU 纹理缓存没有任何控制权，勾不勾几乎看不出差别；现在开关直接驱动运行时削减这些缓存。同一实例实测：开启后 GPU 进程 90 秒内 691→482→352 MB 持续回落，关闭时稳定在 475~571 MB 不再下降（稳态低约 20~25%，图片越多的文档收益越大）。②预览区不再常驻合成层——低显存模式下预览滚动容器退回按需合成，长文档不再整篇常驻光栅缓存。③最小化时不再白抖——周期性合成层自愈在窗口最小化时跳过，省掉每 45 秒一次整窗重排重绘。截图 / 录屏窗口按需重建时自动继承低显存状态。实测：自动化测试 331/331、cargo check 无新增告警。
  • v2.3.11 三个实测驱动的修复 — ①白屏根因闭环：实测确认合成器卡在「内容有脏区但不提交」状态——bounds 抖动、窗口移动、甚至重启 GPU 进程都救不回来，只有页面内容布局变化能踢出（用户按 Ctrl+Q 切侧栏当场救活是决定性证据）。自愈动作全面升级为内容级强制提交，并新增页面就绪钩子与周期兜底（覆盖冷启动 GPU 进程晚就绪、虚拟显示器静默翻转两类窗口期）。②思维导图 / 流程图压成一条斜线：页面隐藏期间渲染会让 mermaid 文本测量全部归零、布局塌缩，现在渲染前等页面可见 + 塌缩自动检测 + 单次重渲染，桌面端与云端同步修复。③局域网共享访客页对齐桌面端：新增编辑 / 预览双视图（公式 / 图表 / 代码高亮全套）、图片正常显示（新增访客专用资产端点，安全边界比桌面版更收紧）、目录栏任意宽度可折叠、配色排版统一。实测：自动化测试 323/323、访客页端到端 18/18、渲染自愈 7/7。
  • v2.3.10 合成层自愈 — 修上一版遗留的那半边：v2.3.9 的 watchdog 靠检查 DOM 判断界面是否正常，但真实故障里 DOM 完全健康（元素齐全、尺寸正确、脚本零报错），只是画面没有被合成到屏幕上，探针一律通过、白屏照旧。本版从渲染管线一侧收口：①强制重绘，对 WebView2 控制器做 bounds 1px 往返，让整棵视觉树重新合成一帧——不重建页面、不丢编辑状态、不动窗口尺寸与最大化状态，全程约 1 帧、肉眼不可感知；②自动触发，启动完成后 2.5 秒 / 6 秒各一次，并在窗口重新聚焦（覆盖「最小化后恢复」这个实测触发点）与缩放 / DPI 变化后各补一次，同类事件 1.5 秒内去抖；③用户出口常显，右下角「显示修复」按钮：点一次强制重绘，5 秒内再点一次改为刷新页面兜底，不必再去猜快捷键。实测：自动化测试 315/315、渲染自愈真浏览器 7/7、启动护栏 22/22、性能预算 9/9。
  • v2.3.9 启动护栏 — 修复「打开应用只剩背景、界面整体空白」的问题：根因是启动期异常被静默吞掉（错误提示写进了一个已被移除的启动画面节点，等于零提示、零重试）。①启动期异常不再静默，任何初始化失败都会显示可操作的错误浮层（错误详情 / 一键恢复 / 复制诊断 / 重新加载）；②主界面可见性 watchdog，启动后若界面未绘制会自动检测并给出恢复入口；③自动重试加上限（最多 2 次，避免持续失败时无限刷新）。启动成功后的运行时错误仍只记录不打扰编辑，既有契约不变。实测：自动化测试 309/309、真浏览器 22/22、性能预算 9/9。
  • v2.3.8 图表与公式彻底离线可用 — 修复桌面端预览里 Mermaid 整片报「库加载失败」的问题：根因是 4 个第三方库仍直连境外 CDN，国内常见线路 TLS 握手被重置（实测 0 字节），云端工作台早已本地化，桌面端却漏了。①Mermaid / KaTeX / Chart.js / ECharts 全部随安装包自带（26 个文件、4.79 MB，含 20 个公式字体，与云端逐字节一致）；②六个加载点全改同源，沙箱内嵌图表页、Markdown 渲染 worker、导出与打印一并受益；③零外部请求，断网、内网、跨境网络下图表与公式都能正常渲染。顺手修掉静态缓存戳的自引用缺陷（现在幂等，内容不变连跑三次戳不动）。实测：自动化测试 301/301、真浏览器 18/18（含 Mermaid 真出 SVG、公式字体 200、零 404、零外部域名请求）。
  • v2.3.7 体验层升级，架构一行未动 — 借鉴新一代编辑器的「空间美学」，只打磨看得见的手感：①每个工作区有自己的颜色（工作区 id 稳定哈希出 6 种柔和主色，也可在「工作路径」里手动指定，只存本机，不改任何数据文件或接口）；②折叠侧栏触缘浮出（鼠标靠近屏幕左缘时侧栏临时滑出、移开收回，纯 CSS 状态机，无常驻定时器）；③阅读区变成文档卡片（只用伪元素加衬底，正文宽度/行高/内边距一个没动，排版与打印不受影响）；④表达力视觉语言补齐（二级标题锚点、行内高亮、表格斑马纹、代码块顶线，全部纯 CSS）。三端 Markdown 渲染器零改动，老文档无需迁移。实测：自动化测试 291 项全绿、体验层真浏览器 11/11、性能预算 9/9；首屏堆 5.23→5.24 MB、DOM +10、输入 P95 5.1~5.6→4.7 ms、0 长任务。
