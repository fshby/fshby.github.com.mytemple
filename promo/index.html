收集与工作区

  • 导入任意磁盘目录作为 Markdown 工作路径

  • 粘贴截图自动压缩并保存到工作区 source/
02

查阅与导航

  • 左侧目录树按文件夹层级展示，支持折叠、隐藏与宽度调整
  • 全局关键词检索，结果定位到文件和首个命中位置
  • 阅读模式显示一级、二级标题目录，点击快速跳转
  • 编辑模式目录与预览同步，长文档保持当前编辑位置

  • Ctrl+Z 撤销、快捷键操作、表格编辑与代码块一键复制
  • 输入“1.”或“一、”回车自动扩展序号，Shift+Enter 保持原行
  • 输入代码时自动补齐围栏，避免重复添加代码标记
  • 实时保存，保存状态清晰反馈，减少频繁手动保存
04

  • 图谱搜索、高亮、范围/深度筛选、孤立节点与未创建引用
  • 节点拖动、牵引动画、缩放、双击打开文档

01 / START

快速开始

用一个工作区建立第一套可持续维护的 Markdown 知识库。

三分钟路径

  1. 下载安装包并完成安装，首次启动时选择默认工作区。
  2. 把 Markdown 文件放入工作区，或使用“新建文件”创建第一篇文档。
  3. 点击刷新，等待目录、标题索引和知识图谱完成更新。
  4. 从左侧目录打开文档，在阅读、编辑、图谱视图间切换。

推荐习惯

  • 一个主题使用一个文件夹，文件名保持稳定。
  • 重要文档开头写标题和标签，便于后续搜索。
  • 粘贴图片后检查工作区的 source 目录。
02 / CONNECT

图谱与标记

让文件、标签和概念形成可追溯的关联，而不是难以阅读的线团。

三种节点

  • 文档节点：代表 Markdown 文件，是关系的来源。
  • 标签节点：来自 Frontmatter 的 tags 或正文中的 #标签。
  • 语义节点：辅助发现相关主题，不替代人工结构。

建立连接

tags: [部署, 运维] | 参考 [[系统设计]] | #故障排查

用双向链接表达文档关系，用标签表达稳定分类。

03 / WRITE

编辑规范

保持文件可读、可搜索、可迁移，降低长期维护成本。

命名建议

  • 使用清晰稳定的名称，例如 系统设计.md。
  • 同一目录避免重名，文件移动优先使用应用内拖动。
  • 标题层级从 # 开始，不跳级。

推荐骨架

# 文档标题 | ## 背景 | ## 结论 | ## 操作步骤 | ## 相关文档

中文序号标题会被识别为二级目录，阅读模式可快速跳转。

04 / DISTILL

AI 蒸馏规范

让 AI 先读取证据，再整理成可复用的知识片段。

输入要求

  1. 先选定工作区或文档范围。
  2. 明确输出类型：摘要、步骤、风险或待办。
  3. 要求保留来源文件和原文位置。

推荐提示词

请整理已确认事实、可执行步骤和未解决问题，并为每条结论标注来源。

无来源的推断必须标记为待验证。

05 / MAINTAIN

AI 维护规则

让 AI 负责检索和建议，关键写入始终由人确认。

允许执行

  • 查找文档、归纳重复内容、建议标签和链接。
  • 生成摘要、PPT 草稿和结构化提纲。
  • 预览 Frontmatter 或文档修改内容。

必须确认

  • 保存、重命名、移动、删除和批量修改文件。
  • 改变工作区路径、索引范围或 AI 配置。
  • 任何无法给出来源的结论。
06 / INDEX

主清单说明

用一份轻量索引帮助 AI 和协作者快速理解知识库边界。

索引应包含

  • 工作区名称、根路径和更新时间。
  • 文档路径、标题、标签、摘要和修改时间。
  • 双向链接、图谱节点和待处理问题。

维护流程

  1. 新增或移动文档后刷新目录。
  2. 执行知识库索引诊断。
  3. 为孤立文档补充标签或相关链接。
  4. 把索引文件纳入备份，不手工覆盖正文。
