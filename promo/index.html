PRODUCT SURFACE

界面预览

围绕阅读、编辑、图谱、工作区与 AI 内容生成六大核心场景。

01

阅读模式

目录、正文与任务勾选分离呈现，支持预估阅读时间与章节快速跳转

02

智能编辑

格式工具栏、实时预览与快捷键面板围绕输入稳定性展开，代码补全与行内对话栏围绕光标位置精准定位

03

知识图谱

文档、标签与语义概念分层展示，轻柔关系线替代高亮噪音，重点节点一目了然

04

工作区管理

多工作区切换、自动保存与增量索引围绕本地目录组织，可迁移、可备份、可离线使用

05

知识脉络

文档间链接关系自动生成知识神经图谱，最新文档自动居中，关系强弱一眼看清

06

AI 文档转图表

AI 生成 Mermaid 图表、Excalidraw 绘图，直接在文档中实时渲染显示

OPTIONAL ASSIST

AI 生成 HTML 动画

最近更新

  • v2.1.13 JSON 格式化全面修复 — MD 中 JSON 代码块自动渲染树形视图，编辑/阅读模式切换时格式化不再失效，processJsonCodeBlocks 统一后处理。
  • v2.1.12 JSON 树形视图三处渲染路径统一 — openDoc 同时渲染到 preview+markdownView，setMode 跳过非 Markdown 的 renderReaderContent。
  • v2.1.11 小文档 BOM 检测修复 — BOM 5 种检测移到 UTF-8 纯解码之前，修复 UTF-8 BOM 文件首字符 U+FEFF 导致 JSON 解析失败。
  • v2.1.10 JSON 预览实时更新修复 — setPreviewVisible 和预览按钮不再强制禁用 JSON 文件，renderCurrentPreviewAsync 增加 JSON 分支。
  • v2.1.9 JSON 宽松解析 + 录屏修复 — 三级解析策略（严格→修复→提取），outCanvas 加入 DOM 确保 captureStream 稳定。
  • v2.1.8 JSON 格式化预览新增 + 小文件编辑器同步修复 — bejson 风格树形视图，CodeMirror view.dispatch 强制刷新内容。
  • v2.1.7 版本自升级修复 — check_update 使用本地 version.json，前端更新对话框（立即下载/稍后提醒）。
  • v2.1.6 录屏鼠标可操作性修复 — 录制窗口 click-through，Alt+M 停止录制，Tauri pick_folder 替代 PowerShell 对话框。
  • v2.1.4 版本自升级缺陷修复 — 后端 check_update 读取 version.json，前端捕获响应弹出更新对话框。
