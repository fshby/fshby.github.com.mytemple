CORE CAPABILITIES

核心能力

不改变 Markdown 文件本身，围绕目录、图谱、检索、主题、性能与日常维护体验补强。

  1. 阅读与修改分开处理 — 阅读时强调目录与预览，编辑时强调输入稳定性与快捷键。
  2. 本地文件优先 — Markdown、图片、索引和工作区配置围绕本地目录组织，可迁移、可备份、可离线。
  3. 知识图谱 — 文档、标签和语义概念分层展示，图谱负责看关系，不替代文档结构。
  4. 内置绘图编辑器 — 轻量 Canvas 绘图（30KB 零依赖），7 种工具 + 撤销重做，保存为 Excalidraw 兼容 JSON。
  5. 代码语法高亮 — 40+ 语言代码块自动高亮，亮/暗主题适配，编辑工具栏按语言快速插入代码块。
  6. AI 内容助手 — 可选接入 Ollama 或 DeepSeek，行内对话、润色翻译、语义检索、AI 生成图表与动画直接内嵌渲染。
  7. 长时间使用不刺眼 — 主题、字号、字体、背景和面板密度可调；柔光护眼主题默认降低对比度。
  8. 检索与维护省心 — 关键词检索、可选语义检索、Frontmatter 标准化、标签补全与主清单索引。
  9. 性能优化围绕真实场景 — 目录懒加载、增量解析、Worker 渲染、图谱自适应帧率。

使用文档

安装与启动

  1. 下载 Windows 安装包（.exe），双击运行。
  2. 选择安装目录，完成安装后桌面会出现快捷方式。
  3. 首次启动需选择工作目录（本地 Markdown 文件夹），之后自动记忆。
  4. 支持多工作路径，在设置中可添加、切换或移除。

文档编写规范

  • 支持标准 Markdown 语法，包括标题、列表、表格、代码块、引用等。
  • Frontmatter 支持(title、date、tags 等元信息字段)。
  • 文档间链接使用 [文本](相对路径.md) 格式，图谱会自动识别关联。
  • 支持数学公式（LaTeX 语法）、Mermaid 图表、Excalidraw 绘图。
  • 高亮标注块：:::tip / :::warning / :::note 等。

图谱标记与维护

  • 文档之间的链接关系自动生成知识神经图谱。
  • 最新文档自动居中，有链接的文档互相引力更强。
  • 拖拽节点松开后按引力规则缓慢复原。
  • 图谱运动参数可在设置中调节，不查看时不占用 GPU。

主题与外观

  • 内置深色、明亮、护眼、柔光四种核心主题。
  • 柔光主题：暖琥珀金强调色，低饱和度，适合长时间写作。
  • 图片主题：上传背景图并自动取色，支持文字明暗切换。
  • 字体、字号、窗口缩放均可自定义，重启后自动恢复。

可选辅助功能

  • 默认关闭，在设置中按需开启，不干扰核心编辑与阅读体验。
  • 支持本地或云端模型接入，模型配置在设置中填写。
  • 提供选中翻译、润色续写、代码补全与生成注释等辅助能力。
  • 问答侧栏助手回复可一键润色、续写或插入到当前文档。
  • 所有辅助功能均可独立开关，按需使用。
