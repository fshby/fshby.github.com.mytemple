最近更新

  • v2.3.9 启动护栏 — 修复「打开应用只剩背景、界面整体空白」的问题：根因是启动期异常被静默吞掉（错误提示写进了一个已被移除的启动画面节点，等于零提示、零重试）。①启动期异常不再静默，任何初始化失败都会显示可操作的错误浮层（错误详情 / 一键恢复 / 复制诊断 / 重新加载）；②主界面可见性 watchdog，启动后若界面未绘制会自动检测并给出恢复入口；③自动重试加上限（最多 2 次，避免持续失败时无限刷新）。启动成功后的运行时错误仍只记录不打扰编辑，既有契约不变。实测：自动化测试 309/309、真浏览器 22/22、性能预算 9/9。
  • v2.3.8 图表与公式彻底离线可用 — 修复桌面端预览里 Mermaid 整片报「库加载失败」的问题：根因是 4 个第三方库仍直连境外 CDN，国内常见线路 TLS 握手被重置（实测 0 字节），云端工作台早已本地化，桌面端却漏了。①Mermaid / KaTeX / Chart.js / ECharts 全部随安装包自带（26 个文件、4.79 MB，含 20 个公式字体，与云端逐字节一致）；②六个加载点全改同源，沙箱内嵌图表页、Markdown 渲染 worker、导出与打印一并受益；③零外部请求，断网、内网、跨境网络下图表与公式都能正常渲染。顺手修掉静态缓存戳的自引用缺陷（现在幂等，内容不变连跑三次戳不动）。实测：自动化测试 301/301、真浏览器 18/18（含 Mermaid 真出 SVG、公式字体 200、零 404、零外部域名请求）。
  • v2.3.7 体验层升级，架构一行未动 — 借鉴新一代编辑器的「空间美学」，只打磨看得见的手感：①每个工作区有自己的颜色（工作区 id 稳定哈希出 6 种柔和主色，也可在「工作路径」里手动指定，只存本机，不改任何数据文件或接口）；②折叠侧栏触缘浮出（鼠标靠近屏幕左缘时侧栏临时滑出、移开收回，纯 CSS 状态机，无常驻定时器）；③阅读区变成文档卡片（只用伪元素加衬底，正文宽度/行高/内边距一个没动，排版与打印不受影响）；④表达力视觉语言补齐（二级标题锚点、行内高亮、表格斑马纹、代码块顶线，全部纯 CSS）。三端 Markdown 渲染器零改动，老文档无需迁移。实测：自动化测试 291 项全绿、体验层真浏览器 11/11、性能预算 9/9；首屏堆 5.23→5.24 MB、DOM +10、输入 P95 5.1~5.6→4.7 ms、0 长任务。
  • v2.3.6 局域网共享真机修复 — 本版由端到端探针在真实安装环境实测驱动，修复三处问题：①访客页无法打开（访客静态资源被鉴权中间件误拦，浏览器打开访客地址只会看到错误提示，现在可正常进入口令配对页）；②关闭共享后端口未即时断开（已建立的浏览器连接仍可继续访问，现在关闭开关后端口立即拒绝新连接、残留连接一律拒绝服务）；③共享开关被设置弹窗的通用输入框样式拉成通栏长条（样式优先级缺陷，现已修复为标准滑动开关，共享工作区的勾选框尺寸同步修正）。
  • v2.3.5 局域网共享增强：可指定共享范围 — 「局域网共享」新增「共享工作区」多选：只把选中的工作区开放给局域网访客（不勾选 = 共享全部），访客侧的目录、文档、搜索、新建、保存全部按范围过滤，白名单外的工作区对访客完全不可见（请求直接 404，不泄露存在性）。同版修复设置面板三处缺陷：开关勾选后无视觉反馈（新增滑动开关样式）、信息区无法隐藏（改用强制隐藏类）、访客地址/口令不刷新（响应解包修正）。修复后开启共享即可正常显示访客地址与口令，复制按钮恢复可用。
  • v2.3.4 局域网共享可用性修复 — 上一版引入的「局域网共享」在真机验证中发现访客配对协议缺陷：访客输入正确口令后可能无法进入访客页、只读/可编辑状态判断失效。本版把访客配对与会话态接口改为与访客前端一致的扁平响应格式，并补自动化回归锁。桌面主界面不受影响；若你已开启共享，升级后访客需重新输入口令（口令本身不变）。
