最近更新

  • v2.3.3 局域网共享来了 + 一轮全面安全加固 — 设置里新增「局域网共享」开关：同一 Wi-Fi/网段的设备用浏览器打开显示的地址、输入 6 位口令，即可浏览、搜索你的工作区文档；可编辑模式下还能新建和修改文档，两人同时改同一篇会明确提示冲突，只读模式随时可切。安全边界按「访客白名单」设计——删除、移动、重命名、目录浏览、AI 等能力对访客根本不存在而不是隐藏；口令连错 5 次锁定 60 秒，数据全程不经过任何外部服务器。同版完成13 项安全审计修复：分享链接改为不可枚举（第三方无法猜链接扫库）、文件读写全链路路径穿越防护、局域网攻击面封堵、保存竞态加锁等。自动化测试 282 项全绿。
  • v2.3.2 分享取图再加一道兜底 — 真实用户踩到了 v2.3.1 修复之外的第三种形态：文档里写着/source/ws_旧id/截图.webp，而工作区重建后 id 已换成新的，按 id 精确取图查无此工作区，图片再次静默丢失。现在改成取图兜底链：先按工作区 id 精确取，取不到自动落到编辑器预览用的同一个端点（按文件名扫描全部工作区）——预览能看到的，分享就一定带得走，两条通道不再分叉。自动化测试 266 项全绿，真浏览器端到端 17/17。
  • v2.3.1 分享链接体验修复三连 — 此前文档里 /source/ws_xxx/截图.webp 这类按工作区归档的图片引用会被当成 source/ 下的子文件夹去找，图片在生成分享那一刻就全部丢失（线上实锤 asset_count=0）；现在按正确语义解析：ws_ 段还原成工作区 id 去取本机字节，写进云端的键与访客侧匹配规则同构。同时补上分享页两处缺口：代码块「复制」按钮此前是个空壳（渲染器只生成了按钮没绑点击，现已绑定并带「已复制/失败」反馈、兼容微信内置浏览器）；长文档没有目录索引（现在右下角浮动「目录」按钮唤起抽屉，逐级缩进、点击跳转、滚动高亮当前小节）。旧分享重新点一次「生成分享链接」即可补齐图片。测试 265 项全绿，真浏览器端到端 13/13 + 目录专项 8/8。
  • v2.3.0 临时分享链接来到桌面端，支持自动过期 — 以前只有手机端能把文档对外分享，现在 PC 端「文件」菜单里直接有「🔗 分享链接…」：选 1 天 / 7 天 / 30 天 / 永久有效，一键生成只读链接，「我的分享」里能看到每条链接的剩余天数并随时撤销。过期不是前端糊弄——云表按到期时间过滤，失效后连内容都取不到，改系统时间也没用；同一文档重复分享复用同一条链接（改内容与有效期），不会堆出一串死链。HTML 文档上传前自动剥离脚本成云端安全形态，本机文件一个字节不动。自动化测试 264 项全绿，真浏览器端到端 13/13。
  • v2.2.7 打开即误报「外部修改」修复 + 高亮全面适配主题 — 修复非 UTF-8 文档（GBK/ANSI 等）刚打开几秒就被提示「文件已被外部修改」的死循环误报（指纹口径统一为磁盘字节），普通保存保留文件原编码、不再静默转 UTF-8。暗色主题下代码高亮的变量、函数、参数颜色此前被深色背景吞掉，现按主题补齐全套配色（浅色 / 暗色 / 护眼 / 柔光 / 图片主题深浅背景各一套），浅色主题 24 项低对比颜色按 WCAG AA 加深（六组主题环境 × 15 种 token 对比度实测 90/90 达标）。设置里的 Markdown 文字高亮与代码语法高亮自定义颜色改为按主题分别记忆，切换主题互不串色，两区各新增「恢复默认颜色」一键回落主题最佳配色；顺带修复自定义代码高亮色重启丢失的旧问题。自动化测试 260 项全绿，真浏览器端到端 21/21。
  • v2.2.6 状态栏编码切换 + 代码编辑增强 — 底部状态栏的编码项（如 UTF-8）现在可以直接点击，弹出菜单选 UTF-8 / UTF-8 (BOM) / ANSI (GBK) / GB18030 / Big5 / UTF-16 LE·BE / Shift_JIS / EUC-KR / Windows-1252，按所选编码保存覆盖文件（GBK 无法表示的字符写成数字字符引用，不丢内容）。代码文件（vbs/vb/js/ts/java/c/cpp/go/py/sh/bat/sql/lua/ini/json 等约 40 种扩展名）编辑时新增缩进参考线（每层级一条竖线，单位自动探测）与语法着色（关键字 / 方法与函数名 / 内置函数 / 字符串 / 数字 / 注释 / 常量分色），Markdown 等其他文件不受影响；顺手修掉两个窗口缩放即报错的预存缺陷（closeAllMenus / applyLayout 引用越界）。自动化测试 251 项全绿，真浏览器端到端 13/13，编码往返（含 GBK / UTF-16 / BOM）11/11。
