MyTemple Knowledge 隐私声明

生效日期：2026 年 8 月 13 日　|　版本：1.8.21　|　运营者：郑堃逢
MyTemple Knowledge 是一款本地优先的 Markdown 文档知识库。除非你主动配置并使用联网服务，核心编辑、阅读、搜索、目录和知识图谱功能均可在本地完成。

一、我们处理哪些信息

根据你使用的功能，软件可能在本机处理以下信息：Markdown 文档及其元数据、工作路径、截图和其他附件、主题与编辑器偏好、搜索索引、知识图谱缓存、AI 配置，以及用于授权校验的机器码和授权凭据。

软件不会要求你创建账号，也不会收集与功能无关的通讯录、浏览历史、精准位置或生物识别信息。

二、本地文件与截图

你选择的工作路径只用于读取、展示、编辑、搜索、移动、复制和保存文件。粘贴的截图会按软件设置压缩后保存到工作区的 source/ 目录，并以 Markdown 路径写入文档。文件内容默认不会上传到我们的服务器。

三、AI 与第三方模型服务

AI 功能默认关闭。使用本地 Ollama 时，请求留在你的设备；使用 DeepSeek 或其他云端服务时，你主动提交的提示词、选中文本、检索片段和生成参数会发送给你选择的服务商，并受其隐私政策约束。请勿在提示词或文档中提交身份证号、密码、支付信息等敏感内容。

API Key 由软件保存于本地配置中，仅用于调用你选择的模型服务；软件不会把 API Key 展示在推荐页或普通日志中。

四、授权与机器码

授权功能会在本机生成设备机器码，用于将授权码绑定到当前设备。机器码用于授权校验，不用于广告画像。解除授权后，本地授权凭据会被删除，软件需要重新授权才能使用受保护功能。

五、更新与网络请求

当你主动检查版本、下载更新、访问帮助页或使用云端 AI 时，软件会发起相应网络请求。请求可能包含版本号、操作系统类型和请求所需的地址参数；核心文档内容不会因版本检查自动上传。

六、数据保存、删除与迁移

文档、截图、索引和设置的保存位置由工作路径和系统用户目录决定。你可以直接删除工作区文件和 source/ 内容，可以在设置中清理索引、解除授权或移除 AI 配置。卸载软件不会自动删除你指定工作区中的 Markdown 文档和截图，请在卸载前自行备份或删除。

七、数据安全

软件通过本地权限边界、路径校验和授权签名校验保护数据。你应妥善保管 Windows 账户、云端 AI API Key 和授权码，并避免把工作区放在任何人都可访问的共享目录中。

八、儿童信息

本软件面向成年人和专业工作场景，不以未成年人为目标用户。我们不会主动收集未成年人个人信息。

九、声明更新

当功能、联网方式或法律要求发生变化时，我们会更新本声明，并在软件推荐页或版本说明中标明新的生效日期。继续使用更新后的软件即表示你已阅读相关变更。

十、联系我们
